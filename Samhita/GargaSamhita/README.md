# Garga Samhita — गार्गसंहिता

**Author:** Garga (traditional attribution)
**Period:** Ancient — date disputed, possibly pre-Varahamihira
**Status: not yet digitized.**

Garga is one of the earliest named Jyotish authorities, cited by Varahamihira and others.
The Garga Samhita covers omens, planetary portents, and mundane predictions. Multiple
recensions exist; the complete text is difficult to establish.

Note: distinct from the devotional *Garga Samhita* (on Krishna's life), which is a
Vaishnava Purana.

## The waiting source is the other Garga Samhita — do not digitize it here

`../sanskrit-texts-sources/Samhita/GargaSamhita/3003.txt` is filed under this directory's
name but is **not this text**. Its colophon reads:

> इति श्रीमद्गर्गसंहितायां अश्वमेधखण्डे श्रीकृष्णसहस्रनामवर्णनं नामैकोनषष्टितमोऽध्यायः ॥ अध्याय ५९॥

Ashvamedha Khanda is a division of the **Vaishnava Purana**, not of the astrological work
described above. The file is one chapter — the Krishna Sahasranama Stotram, 127 shlokas —
of a different work that happens to share the title.

It was digitized on 2026-08-22 and **relocated 2026-08-23** to
`Tushar/Youvan/texts/Stotra/KrishnaSahasranamaStotram/`, under the Jyotisha/Youvan
ownership split (`Vipin Kaushik/CLAUDE.md` §"Content / texts ownership"). Precedent: the
2026-06-20 SamudrikShastra scope call in
`Vipin Kaushik/propagation/state/sanskrit-texts/DECISIONS.md`.

The source `.txt` is left in place in the sources repo (Youvan has no sources tier); the
Youvan README points back at it.

**So this directory has no source waiting.** Any doc listing GargaSamhita among texts
whose sources are ready is describing the relocated file, not this one. Digitizing the
Jyotish Garga Samhita requires sourcing it first — Internet Archive (partial), Indian
manuscript repositories.
