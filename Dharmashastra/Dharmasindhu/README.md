# Dharmasindhu — धर्मसिन्धु

**Author:** Kashinatha Upadhyaya (Anantadeva)
**Period:** 1790 CE
**Status: Not yet digitized in this collection**

A later, highly practical Nibandha digest covering both **vrata/festival
determination** and **muhurta**. Widely used by panchang-makers because it
condenses the Nirnaya Sindhu material into ready rules. Dual-use here:

1. **Festivals** — same kala-nirnaya / tithi-pervasion rules as Nirnaya Sindhu;
   useful as a corroborating source for the AstroAcharya festivals catalog.
2. **Muhurta** — it is the named source for the **"Dharmasindhu" Durmuhurta
   school** in `astroacharya/.../calculations/muhurta/durmuhurta.py` (the school
   whose weekday positions differ from Muhurta Chintamani). Digitizing this lets
   that school's table be verified against the text.

> Audit note (the reason this folder exists): the third durmuhurta school in the
> same file, labelled **"Brihat Samhita"**, was checked against the Brihat
> Samhita already present in `Samhita/BrihatSamhita/` and **no durmuhurta verse
> exists there** — the attribution is unbacked. Dharmasindhu and Muhurta
> Chintamani are the two muhurta schools that do have real textual sources to
> digitize.
