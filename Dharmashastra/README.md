# Dharmashastra / Nibandha — धर्मशास्त्र · निबन्ध (Festival & Vrata Determination)

The Nibandha (digest) literature of Dharmashastra is where **festival and vrata
dates** are determined — which tithi, with which pervasion rule (vyapini), which
overrides when a tithi is clipped or doubled, how a festival shifts when its
nakshatra/yoga condition fails. This is a separate literature from Jyotisha's
three skandhas (Hora, Samhita, Siddhanta): the astronomy supplies the tithi/
nakshatra instants, but the *rule for which day the festival falls on* is
Dharmashastra.

These texts are the textual basis for the AstroAcharya festivals engine
(`astroacharya/app/core/timeline/` + the vyapini matcher, festivals drik-exact
catalog). That engine currently implements the Nirnaya-Sindhu-family rules
(sankranti civil-date, Vijayadashami, Holika Bhadra avoidance, Diwali pervasion)
against **drikpanchang computational conventions**, with no Nibandha text in this
corpus to cite back to. Digitizing these closes that gap.
